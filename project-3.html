Home Page | Product Listing | Quick View | Cart Overview

Live Link

Overview

This project focused on improving the user experience of the ZARA Clothing App. The wireframe was designed to address pain points in navigation and shopping flow while introducing innovative features like dark mode and AI recommendations.

Process:
1. Research:
Analyzed the current app for usability issues. Studied user behavior to identify common challenges.
2. Wireframing (Using Figma) Created low-fidelity designs to focus on layout and structure. Iterated designs based on feedback.
3. Prototyping Developed a clickable prototype for testing user flows.

Features:
Home Page: Seasonal highlights and product categories.
Product Listing: Grid layout with interactive filters.
View: Easy access to product details.
Overview: Simplified checkout with delivery details.

New Enhancements:
Dark Mode for accessibility.
AI-based recommendations for personalized shopping.
Real-time interactive filters.

Used:
Figma for wireframing and prototyping.

Conclusion:
This project reflects my journey as a beginner UI/UX designer.
It showcases how thoughtful design can enhance user experience while aligning with the brand’s identity.
